# Security Policy

## Supported Versions

The latest release and the `main` branch are currently supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through GitHub:

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide details about the vulnerability, including steps to reproduce it and any relevant impact.

Please do **not** report security vulnerabilities through public issues, pull requests, or discussions.

## Scope

The following components are in scope:

- `action.yml`
- `app/`
- `.github/workflows/`
- `app/mcp_server.py`
- `index.html`

## Out of Scope

The following are out of scope:

- Vulnerabilities in dependencies. Please report these to the relevant dependency's project.
- Vulnerabilities in repositories listed in the dataset.

## What to Expect

We will provide a first response within **7 days** of receiving your vulnerability report.
